# 孟子文言閱讀挑戰

延伸國中課文〈生於憂患，死於安樂〉的線上閱讀測驗。收錄十則孟子的寓言和故事，每則附四格漫畫，並有 3 題仿會考題型的選擇題。

- 十則篇目：揠苗助長、一暴十寒、五十步笑百步、月攘一雞、齊人驕其妻妾、緣木求魚、一傅眾咻、校人烹魚、王顧左右而言他、孟母三遷（《列女傳》）
- 交卷後立刻顯示對錯、解析和白話大意
- 班級成績：累計排行榜（每篇取最高分）、各篇答對率、全班易錯題
- 作答紀錄：每次交卷的完成時間和用時，自動標記「太快」「全選同一項」等疑似亂答的作答

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 網頁本體 |
| `config.js` | 設定 Google 試算表網址 |
| `apps-script/Code.gs` | 放在 Google 試算表裡的成績後端程式 |

## 一、開啟 GitHub Pages

1. 到這個 repo 的 **Settings → Pages**。
2. **Source** 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
3. 等大約一分鐘，網址會是 `https://<帳號>.github.io/<repo 名稱>/`。

這時網頁已經可以用，但成績只存在每台裝置自己的瀏覽器裡（右上角顯示「本機模式」）。

## 二、設定全班成績（Google 試算表）

1. 用學校的 Google 帳號開一份新的 Google 試算表，名稱自訂，例如「孟子閱讀成績」。
2. 選單 **擴充功能 → Apps Script**，把編輯器裡原本的程式全部刪掉，貼上 `apps-script/Code.gs` 的內容。
3. 把第 8 行的 `change-me` 改成你自己的教師密碼。學生看不到這個密碼。
4. 按存檔，再按右上角 **部署 → 新增部署作業**：
   - 類型選「網頁應用程式」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按部署。第一次部署要授權，依畫面指示允許即可。
5. 複製產生的「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
6. 回到 GitHub，打開 `config.js`，按鉛筆圖示編輯，把網址貼進 `sheetApi: ""` 的引號裡，再按 Commit。
7. 重新整理網頁，右上角顯示「班級成績已連線」就完成了。

完成後，試算表裡會自動出現兩個工作表：

- **成績**：每位學生每篇一列，供網頁讀取，請不要手動改欄位。
- **作答紀錄**：每次交卷一列，有完成時間、用時和作答內容，可以直接篩選和排序。

> 之後如果修改了 Code.gs，要到 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 再部署，網址不會變。

## 老師檢視

- 學生在「班級成績」只看得到排行榜。
- 老師在「班級成績」頁輸入教師密碼登入後，才看得到作答紀錄（完成時間、用時、疑似亂答）、各篇答對率、易錯題，以及教師區。
- 密碼由 Google 試算表那邊驗證，沒登入的人拿不到作答紀錄。
- 老師登入後，按「大屏展示」可投影全班即時成績（排行榜前十名、各篇完成人數與答對率，每 15 秒自動更新；不顯示疑似亂答與用時）。直接網址：`https://littlejocelyn2-hfjh.github.io/mengzi-reading/#screen`
- 老師直接看成績的網址：`https://littlejocelyn2-hfjh.github.io/mengzi-reading/#scores`

## 注意事項

- 學生不用登入，只要填班級、座號、姓名。若學生故意填別人的座號，成績會記到別人名下；有疑慮時，可在「作答紀錄」工作表查看時間來核對。
- 網頁是公開的，任何拿到網址的人都能作答。成績資料只存在你的 Google 試算表裡。
- 「疑似亂答」只是提醒，請老師再確認。
